01 / Challenge

The learning or performance need

Travelers need language they can recognize and use inside a real interaction, not only vocabulary they can recall in isolation. The challenge was to keep the experience approachable for beginners while still requiring meaningful interpretation and response choices.

Design response

I built each mission around a recognizable need, such as taking a taxi, ordering food, shopping, checking into a hotel, navigating a hospital, or using the subway. A shared lesson engine creates consistency while mission-specific content changes the situation, characters, choices, vocabulary, and task logic.

02 / Design decisions

How the experience was shaped

01

Make choices consequential

Destinations, products, sizes, symptoms, and service requests determine what the learner must understand or say later in the conversation.

02

Layer support without removing the task

Learners can request audio, slow audio, romanization, translations, vocabulary, and word-level help while the Korean prompt and response decision remain visible.

03

Connect performance and practice

Missions create a reason to communicate. The Study Hub then supports reading, visual, audio, and writing practice using vocabulary gathered across missions.

04

Use feedback to revise the design

Informal testing revealed that an implied haggling goal was not clear. The next iteration adds a direct instruction so the learner understands the communication task before being assessed.

03 / Selected evidence

Inside the work

04 / Evaluation

Current evidence and next iteration

The next phase is structured learner testing, continued Korean-language review, accessibility testing, and refinement of advanced listening and speaking practice.

  • Nine fully playable missions use a consistent interaction pattern with mission-specific logic.
  • Informal usability testing identified a gap between the intended task and the learner's understanding.
  • The prototype has been tested and debugged across iterative builds.
  • No formal learning-outcome study has been conducted yet.
